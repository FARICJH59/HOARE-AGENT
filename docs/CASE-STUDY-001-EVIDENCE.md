# HOARE Case Study #1 — Evidence Boundary

**Provenance:** 2026-09-16

The controlled authorization boundary is evidence-carrying. Authority metadata includes source, evidence references, exact scope, audit correlation, tenant, product, action, mode, issuance, expiration, and status.

A request is not authorized merely because a lease exists: the lease must match the exact requested context and contain the required evidence and scope. Authorization remains separate from execution and physical actuation.
